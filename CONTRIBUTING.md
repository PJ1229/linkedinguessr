# Contributing

Use branches such as `feat/clue-rpc`, `fix/mobile-focus`, or `chore/ci`. Use conventional commits (`feat:`, `fix:`, `chore:`, `docs:`). Before a PR run `npm run lint`, `npm run typecheck`, and `npm test`.

PRs should explain behavior, tests, screenshots for UI work, and privacy implications. Do not add real people, imported LinkedIn data, secrets, or unapproved career data. Suggest features through the feature-request issue template.
